# Business Sales Performance Dashboard
## Future Interns Data Science & Analytics Task 1 - 2026

## Project Overview
A business sales performance analysis built in Power BI using the Superstore dataset.
The dashboard analyzes revenue trends, product performance, and regional profitability
to provide actionable business insights.

## Tools Used
- Power BI Desktop
- Microsoft Excel / CSV (Superstore Dataset)

## Key Insights
- Total Sales: R2,30M
- Total Profit: R286,40K
- Profit Margin: 12,47%
- Total Orders: 5K
- Technology is the highest performing category
- West region leads in total sales
